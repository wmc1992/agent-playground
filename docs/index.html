02 · Details

小而完整的实现

没有框架、没有构建步骤、没有第三方 CDN，打开页面即可运行。

零依赖

原生 HTML、CSS 与 JavaScript，没有任何框架或外部资源，首屏加载只需要三个静态文件。

Canvas 粒子引擎

基于 requestAnimationFrame 的轻量模拟，自动适配屏幕尺寸与像素密度，页面离开视野时自动休眠。

克制而好用

响应式布局、键盘可操作的控件、跟随系统的深浅色偏好，并尊重「减少动态效果」设置。

03 · About

关于这个站点

星岚由 AI agent 在 agent-playground 仓库中从零构建：一个页面、一份样式、一段脚本，再加上一条 GitHub Actions 工作流。

每次向主分支推送，工作流都会把 docs/ 目录打包发布到 GitHub Pages；页面本身是纯静态资源，不需要任何服务器。
